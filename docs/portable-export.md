# Переносимая выгрузка

Без скачивания медиа панель отдаёт выбранный файл с именем `Имя канала_YYYY-MM-DD_HH-MM-SS.ext`.
Для медиа и HTML создаётся ZIP с таким же именем и одной одноимённой папкой внутри.
Распакуйте ZIP целиком и откройте `index.html` или `messages.html`: страницы истории используют относительные
ссылки на фото, видео, голосовые сообщения и документы. JSONL и выбранный дополнительный
формат находятся рядом. Идентификатор задания остаётся внутренним.

Папки `photos`, `video_files`, `voice_messages`, `round_video_messages`, `animations`,
`stickers`, `files` следуют организации Telegram Desktop. JSON использует основные поля
официального экспорта (`id`, `from`, `from_id`, `forwarded_from`, `reply_to_message_id`,
`text`, `text_entities`, относительные `photo`/`file`). Полные исходные записи TGX
сохраняются в JSONL. HTML использует отдельные блоки авторов, пересылок и ответов;
ссылки ответов работают между страницами, а отсутствующие сообщения явно отмечаются.
TXT показывает автора, `#номер -> #номер ответа`, пересылку и путь к файлу.

Источники: [описание экспорта Telegram](https://telegram.org/blog/export-and-more),
[реализация папок Telegram Desktop](https://github.com/telegramdesktop/tdesktop/blob/dev/Telegram/SourceFiles/export/data/export_data_types.cpp).

При FloodWait сервис ждёт `retry_after` и автоматически продолжает с сохранённого курсора.
Ожидающее задание не задерживает другие готовые задания. Ручная пауза остаётся ручной.
В панели есть выбор сохранённых профилей и кнопка «Добавить аккаунт»; у каждого своя сессия.
