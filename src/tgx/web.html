Выйти из Telegram?

Сессия Telegram завершится. Её файлы, сохранённые API-реквизиты и данные формы будут удалены. Активные выгрузки приостановятся. Ваши архивы останутся в заданиях.

API-реквизиты используются всеми профилями этого сервера. После их удаления для следующего подключения понадобится первичная настройка.
